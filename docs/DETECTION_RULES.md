# 暴发探测的实际实现规则

本文对应 `data_preprocessing.R` 与 `outbreak_detection.R`。可用来说明作品如何从原始报卡数据走到预警线索；所有参数和能力以代码为准。这里的“预警”表示达到筛查规则，仍需核对报卡、场所与流行病学关联。

## 1. 先定义可纳入分析的记录

处理顺序很重要：**导入 → 完全重复去重 → 同卡保留最新版本 → 有效性过滤 → 纳入分析**。必须先选择最新版本，再过滤删除状态，否则“旧卡有效、最新版本已删除”的病例可能错误留在结果中。

| 步骤 | 当前实现 |
| --- | --- |
| 编码和列名 | 尝试 UTF-8、GB18030，要求存在 `疾病名称` 和 `发病日期`；缺少可选字段补空；部分删除字段兼容别名 |
| 空值与文本 | 换行/制表符和连续空白规范化；空字符串、`.`、`NA`、`N/A`、`NULL` 等转空值 |
| 完全重复 | 规范化后的所有列完全相同则只留一行 |
| 同卡多版本 | 优先 `卡片ID`，其次 `卡片编号`；按订正终审时间优先、缺失时用录入时间排序；时间相同则后读入行优先；两种编号都缺失时保留各行身份 |
| 无效卡 | 状态出现删除/退卡/作废；审核出现这些词或未纳入统计；存在删除时间或非空删除原因，均不纳入 |
| 日期与病种 | 按 Asia/Shanghai 解析日期；发病日期缺失/无效、病种缺失的记录不纳入 |
| 标准化字段 | 字典匹配管理级别/传播途径；先用出生日期与发病日期估算年龄，不能计算时解析年龄文字；规范性别与年龄组 |

去重是**报卡版本去重**，不是跨 ID 的患者实体识别。缺失状态被视为空，不代表已核实有效。清洗统计会列出各环节排除条数；不应把被排除病例默认为“没有病例”。

## 2. 从两个文本字段提取场所

`患者工作单位` 与 `现住详细地址` 是两个独立通道。它们分别形成候选场所，同一病例可能在两个通道出现。

1. 规范空白与标点，修正少量固定写法，例如 `幼儿圆/幼儿苑/幼儿殓园 → 幼儿园`、`小学校 → 小学`。
2. 对 `年级、班、组、科、室、病区、单元、栋、楼、号` 前的常见中文数字做固定规则替换，例如 `三年级二班 → 3年级2班`。
3. 匹配**第一个机构后缀**，之前及该后缀作为核心机构，其后文本作为子部门。如 `演示晨光小学（三年级二班）` 得到 `演示晨光小学` 与 `3年级2班`；`演示晨光小学学生宿舍` 得到同一小学与 `学生宿舍`。
4. 核心机构必须存在；扣除机构后缀和已配置的昆明地区行政词后，特异文字至少 2 个字符；清洗后的全文还必须命中重点场所关键词。

后缀包括小学、中学、学校、大学、学院、幼儿园、医院、卫生院、诊所、养老院等。关键词与后缀是两道不同条件：只修改关键词不会自动扩充后缀词典。例如需要识别新的场所类型时，可能要同时扩充两者。

这是固定文本规则，**没有通用错字纠正、模糊匹配、地址地理编码或命名实体识别模型**。首个后缀规则也可能把 `某大学附属医院` 截为 `某大学`；此类复合机构名称需要人工核实。行政前缀目前保留在核心机构名称中，所以 `昆明市演示晨光小学` 与 `演示晨光小学` 可能仍分成两组；不同校区、简称和同名机构也需要人工核对。

## 3. 同组后进行发病日期窗口计数

探测统一使用 `发病日期`，不切换到诊断、录入或订正日期。总体图表的日期口径与探测口径应分别说明。

分组键为：

```text
场所类型 + 场所地区 + 核心机构 + 原始疾病名称
```

`场所地区` 优先使用现住地址国标转换的 6 位行政代码，缺失时用已提取区县，仍缺失则标记“地区未知”。它是**居住地代理**，不能等同机构真实地址。这样可减少跨地区同名机构混聚，但也可能把跨区就学、就业的真实同机构病例拆开；地区全部未知时仍可能混聚同名机构。

同一病种使用原始 `疾病名称` 精确分组；字典的“标准病种”用于展示与筛选，并不在这里无条件合并。这样避免将不同肝炎亚型合并，但会漏合“流感/流行性感冒”等不同写法。数据提供方应统一病名，后续可引入经过审核的“探测病种映射”。

设最长窗口为 `W` 个自然日、阈值为 `T` 例：

```text
对该组每个唯一发病日期 s：
  统计发病日期落在 [s, s + W - 1] 的病例数 n(s)
选择 n(s) 最大的窗口；并列时取较早窗口
若最大病例数 ≥ T，形成机构级预警
```

默认 `W = 14`、`T = 3`。14 天包括起止两天，例如 10 月 1 日至 10 月 14 日；10 月 15 日不属于这个窗口。报告中的实际时间跨度为 `最晚发病日 − 最早发病日 + 1`。

目前每个分组只输出一个病例最多的窗口，**不会完整枚举查询期间所有彼此分离的事件**。长时间查询应结合短周期复查。窗口仅统计查询范围内的记录，查询起点之前的病例不自动带入。

## 4. 再判断子部门是否达到阈值

只使用机构级预警最佳窗口内的卡片：

- 同一子部门、同一原始病名病例数达到同一阈值 `T`，显示“班级/科室聚集”。
- 机构达到阈值，但没有已填写的子部门达到阈值，显示“机构级聚集，子部门未达阈值”。其中可包含未填班级/科室的病例。
- 如果已经有达阈值子部门，该机构不会另外生成一行“机构内散发”提示；仍可查看机构级表了解其他子部门。

“机构内散发”在这里是一个界面汇总标签，不能推导为这些病例已证实没有关联。

## 5. 可复现的合成例子

使用 `data/demo_surveillance.csv`，预警日期选 2026-10-01 至 2026-10-08，阈值 3，窗口 14：

| 虚构机构 | 同病名病例 | 子部门结果 |
| --- | --- | --- |
| 演示晨光小学 | 流行性感冒 6 例 | 三年级二班的不同写法统一后 3 例，达到班级阈值 |
| 演示星河幼儿园 | 手足口病 6 例 | 幼儿圆/幼儿苑写法修正；大班 3 例达到阈值 |
| 演示云杉中学 | 水痘 4 例 | 四个班各 1 例，只有机构达到阈值 |

该例子用于检验规则是否按预期执行，不能用来声称真实世界的灵敏度、特异度或准确率。

## 6. 使用边界与下一步验证

- 固定阈值没有纳入病种潜伏期、季节性基线、机构人口分母或既往发病水平。不同病种和场所需经业务审核确定参数。
- 现住地址出现医院名称可能是附近住址，并不证明暴露发生在该医院。关键词匹配是筛查线索。
- 两个通道的预警数不能直接相加当作独立事件数；同一卡片可能出现在不同预警中。
- 缺少机构名称、错别字超出字典、跨 ID 重复报卡、未知地区和不同病名写法均会影响结果。
- 正式评价应先构建人工核实的事件集，再按病种/场所比较检出率、误报率与预警时间，不能用本合成数据代替效果评价。

后续可逐步增加机构主数据和校区 ID、经过审核的病名映射、按病种阈值配置、历史基线模型与多事件窗口合并。以上属于后续改进方向，不是当前已实现能力。
